# Repurpose — Extraer content atoms de piezas largas

Reference para el comando `repurpose`. Toma contenido largo (artículo web, podcast transcripción, presentación, email largo) y extrae unidades autocontenidas para redes sociales.

---

## Content Pyramid

```
PILLAR (1 pieza, alto esfuerzo)
  → artículo web, podcast, webinar, presentación
    ↓
DERIVATIVE (3-5 piezas, esfuerzo medio)
  → threads, carousels, posts largos LinkedIn
    ↓
MICRO (10-20 piezas, bajo esfuerzo)
  → tweets, stories, quotes, datos sueltos
```

De 1 pieza pilar se extraen 15-25 assets sociales.

---

## Tipos de atoms

| Atom | Qué es | Mejor destino |
|------|--------|---------------|
| **Quotable** | Frase potente que funciona sola | X tweet, IG story |
| **Story arc** | Narrativa con inicio-nudo-desenlace | LinkedIn post, X thread |
| **Tactical tip** | Paso concreto y accionable | X, LinkedIn, carousel slide |
| **Contrarian take** | Opinión que genera debate | X, LinkedIn |
| **Data callout** | Dato con contexto que sorprende | Cualquiera (como hook) |
| **Behind-scenes** | Proceso, decisión, making-of | LinkedIn, IG |

---

## Workflow

```
1. Recibir fuente (URL, texto, o path a archivo)
2. Leer contenido completo
3. Identificar atoms por tipo (mínimo 8-10 de una pieza de 1500+ palabras)
4. Para cada atom: etiquetar tipo + mejor plataforma + formato sugerido
5. Presentar lista al operador
6. Si aprobado → pasar atoms a `create` para desarrollo completo
```

---

## Regla de adaptación

Cada atom se ADAPTA al destino — no se copia literal. Un párrafo de un artículo no es un tweet. La extracción identifica la IDEA; el comando `create` la reformatea al canal.

Nunca cross-postear contenido idéntico entre plataformas. Las audiencias se solapan y lo notan.
